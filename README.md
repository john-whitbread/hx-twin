# hx-twin

Digital twin of a generic nuclear service-water shell-and-tube heat exchanger, calibrated against CFD, for monitoring design-basis margin.

**Status:** Phase 0 – setup

## Scope
Educational prototype. Generic component, illustrative parameters,
synthetic data. Not a model of any operating station and not a
qualified engineering tool.

## Structure
- `notes/` – decision log and hand derivations
- `notebooks/` – exploratory calculations
- `src/hx_twin/` – twin source code
- `tests/` – automated verification
- `cfd/` – Ansys case documentation and summary results
- `docs/` – requirements, design, V&V

## Tools
Python · Ansys Fluent / Mechanical / optiSLang (Student 2026 R1) · Azure Digital Twins
